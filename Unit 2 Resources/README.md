## Audit notes

All PDFs were converted with MarkItDown and all 91 pages were visually surveyed; diagrams and unreadable answer-key text were checked in rendered pages. Image conversion produced no text, so all 20 screenshots were reviewed visually. Generated extraction and rendering files are working files, not original resources.

The root `codedb.snapshot` is repository tooling data, and `.DS_Store` is macOS metadata; neither is a class resource. Existing Unit 1 files were left in place.
